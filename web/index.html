micropython-hardware

Board configs, display/touch drivers, and hardware docs for MicroPython and CircuitPython. Install board packages with mip on MicroPython (and CP-compatible paths via the MIP index), or pip for desktop configs such as pydisplay-desktop. Documentation is markdown in this repo, published here on GitHub Pages (not Read the Docs). pydisplay core API docs stay on pydisplay.readthedocs.io.
