pydevices

pydevices — Core hardware driver engine & board contract.

pydevices is the core product of the PyDevices ecosystem. It establishes the standardized PyDevices Board Contract (board_config.py), lazy peripheral management (boarddev), eager UI hardware initialization, and unified display abstractions (displaydev) across MicroPython, CircuitPython, CPython, PyScript, and Android.

Architecture & Core Subsystems

The key pillars of the PyDevices hardware abstraction layer.

board_config.py Contract

Standardized MCU pinout definitions and bus initializations enabling user code to run unchanged on any target development board.

displaydev Abstraction

Unified display driver interface supporting SPI, I80, RGB, and DSI panels with automatic frame-buffer blitting and rotation.

audiodev Subsystem

Portable PCM audio output/input abstractions for microcontrollers (I2S, PWM DAC) and desktop host backends.

Lazy boarddev Peripheral Management

Hardware peripherals are initialized on-demand when accessed, saving RAM and power on constrained devices.

Quickstart & Preferred Search Paths

MicroPython MIP and canonical environment variable settings. 
# Install pydevices core package via MicroPython MIP:
import mip
mip.install("github:PyDevices/pydevices")

# Preferred environment path settings (Linux / macOS):
export MICROPYPATH=".:.frozen:lib:utils:~/.micropython/lib:/usr/lib/micropython"
export PYTHONPATH=".:lib:utils"
